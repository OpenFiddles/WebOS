A closer look at WebOS

More than a desktop.
A platform you shape.

WebOS is a browser-based operating environment. It brings windows, apps, files, creative tools, customization, and developer capabilities together in one workspace that can run on desktop and mobile browsers.

What WebOS can do

A tour of the features represented in the current WebOS project. Availability can vary by browser, device, and the maturity of an individual feature.

Desktop workspace

Launch a full-screen desktop inside your browser, with a taskbar, application launcher, desktop shortcuts, dock, clock, notifications, and multiple open windows.

Window management

Open, focus, move, resize, minimize, maximize, and close app windows. Use draggable window chrome and edge or corner resizing.

Virtual desktops

Create and switch between persistent workspaces, keeping different sets of work organized. The workspace manager provides controls for managing them.

App launcher

Find apps with search, browse app categories, and use pinned and recently used app views to get back to work quickly.

Files and storage

Browse the WebOS virtual filesystem, organize files and folders, and use app-scoped browser storage. Storage estimates and persistent-storage requests depend on browser support.

Notes and documents

Create and work with notes, markdown-oriented content, and notebook-style workflows inside the desktop.

Creative tools

Use drawing and paint tools, image and media utilities, camera access where supported, audio recording, video playback, printing, and animation creation.

Personal appearance

Customize the desktop experience with wallpapers, accent and theme choices, desktop layouts, dock and taskbar presentation, window styles, and motion preferences.

Liquid Glass effects

Experiment with translucent surfaces, layered blur, reflections, and visual refraction. These effects are experimental and may vary with browser and GPU performance.

Notifications and sessions

Receive in-OS notifications, inspect session and system information, and use available lock and session controls.

Task and system tools

Inspect WebOS-managed app processes, review storage and network hints, and check device and runtime capabilities. These are browser-level views, not unrestricted host operating-system diagnostics.

Mobile edition

Use a mobile-oriented launcher and workspace layout, with responsive controls designed for touch screens and smaller displays.

Important distinction: WebOS runs inside the browser. It does not replace your computer's installed operating system, and browser security rules still apply. It cannot freely inspect host processes, Wi-Fi passwords, or arbitrary device files.

A platform for builders

WebOS includes tools and APIs intended to make the environment extensible, from building small apps to experimenting with lower-level browser capabilities.

Available in project

App Creator

Create and test WebOS apps, including HTML-based app experiences and developer-oriented workspaces.

Available in project

App registry and lifecycle

Register and launch applications through the shared app registry, with app identity, lifecycle tracking, and app-facing APIs.

Permission-aware

WebOS app API

Apps can request supported permissions and use provided interfaces for files, app storage, windows, clipboard, notifications, and system information.

Browser dependent

Hardware APIs

Capability checks and user-initiated access paths cover WebUSB, Web Serial, WebHID, Bluetooth, WebGPU, media codecs, and WebXR where supported.

Experimental

WebAssembly runtime

Explore WebAssembly and WASM-related tooling, including runtime support and developer workflows. It does not provide unrestricted native execution.

Developer tools

Mobile preview and tests

Preview the mobile edition at common phone and tablet viewport sizes and run browser-side smoke checks for key mobile components.

Experimental

Virtual machine sandbox

WebOS is being expanded toward browser-hosted virtual machine experiences. VM sandbox access is intended as a paid hosted capability, not a promise of a currently available service.

Browser storage

App data isolation

Apps can use app-scoped IndexedDB storage and request storage permissions. This is cooperative separation within the browser, not a security boundary between hostile same-origin scripts.

Open platform direction

Web technologies

Built around HTML, CSS, JavaScript, browser APIs, and WebAssembly, with progressive enhancement as browser capabilities allow.

Hardware access requires a compatible browser, secure context where required, user permission, and often a direct user gesture. A capability being listed does not mean every device supports it.

Who WebOS is for

One browser workspace, with different service levels for different kinds of users.

Individuals

A free personal desktop for everyday use, customization, local apps, and creative experiments.

Teams and businesses

A planned shared environment for teams, people directories, roles, shared apps and files, and collaboration history.

Schools and educators

A planned education offering for school-managed accounts, classrooms, teacher and student workspaces, and learning tools.

Enterprise organizations

A planned organization tier for centralized administration, policy controls, audit history, and managed cloud services.
