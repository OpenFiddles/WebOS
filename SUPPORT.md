# Getting Help

- **Usage and setup:** start with the [README](README.md) and the in-app Documentation app.
- **Bug reports and feature requests:** use the GitLab project's issue tracker: https://gitlab.com/openfiddles/WebOS/-/issues
- **Code contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security concerns:** follow the private reporting process in [SECURITY.md](SECURITY.md).

When reporting a bug, include the browser and operating system, the steps to reproduce it, expected behavior, actual behavior, and relevant console errors. Remove credentials, tokens, and personal information from logs and screenshots.
